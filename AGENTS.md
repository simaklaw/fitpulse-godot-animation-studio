# AGENTS.md — правила для AI-агентов FitPulse Animation Studio

Читать **перед** любой работой в этом репозитории. Полный план: [`docs/AGENT_PLAN.md`](docs/AGENT_PLAN.md).

Координатор: владелец (simaklaw) + архитектор. Язык отчётов: русский. Владелец работает с телефона (Godot 4.7.2 Android-редактор; локальный CLI/headless недоступен). Проверка — через CI-артефакты и логи GitHub Actions.

## Жёсткие правила (нарушение = остановка)

1. **ЗАПРЕЩЕНО** процедурно генерировать движения (углы костей, ключевые кадры, IK-«починки» в стиле `grip_*.js`). Движения — **ТОЛЬКО** из AnimStack пака/mocap. ИИ строит конвейер вокруг реального движения, а не сочиняет движение.
2. **ЗАПРЕЩЕНО** использовать как руководство: `ANIMATION_CODE.md`, `ANIMATION_CODE_v2.md`, `grip_*.js`, `bake*.mjs`, `build_*.mjs`, `back_squat.gd`, `bodyweight_squat.gd` — это **архив** провалившихся экспериментов (см. `archive/`). Читать только для исторической справки.
3. **ЗАПРЕЩЕНО** ослаблять валидаторы, gates, тесты ради зелёного CI. Чинить ассет или конвейер, не проверку. Контракты с forma синхронизировать явно.
4. **ЗАПРЕЩЕНО** ставить `automated_qa_passed` / `human_approved` без доказательств: реальные медиа обоих профилей, SHA-256, commit-источник, пройденные gates. `human_approved` ставит **только** владелец после визуального ревью.
5. **ЗАПРЕЩЕНО** коммитить в git лицензионные исходники и производные: FBX пака, извлечённые GLB с анимацией пака, текстуры пака. Промежуточные GLB — только в Cloudflare R2. Публичные артефакты CI — только готовые рендеры и отчёты. CC0-ассеты Quaternius коммитить можно.
6. Секреты (R2, API) — только GitHub Secrets. Никогда в коде/логах/issues.
7. В `forma` **не трогать** логику приложения. Только медиа + manifest + тесты контракта медиа.
8. Одна задача = одна ветка = один PR. Прямые push в `main` запрещены. Ветки: `agent-a/T1.1-...`, `agent-b/T0.1-...`. Не force-push в чужие ветки.
9. Новые инструменты/зависимости — только с одобрения владельца. Mesh2Motion не подключать к обязательному CI (см. `MESH2MOTION_RETARGET_TRIAL.md`).
10. После 2 неудачных попыток починить один и тот же дефект — **СТОП**, вопрос владельцу (см. §8 плана).

## Роли

- **Агент A (pipeline):** T1.*, T3.*, T4.* — Godot/Blender/CI/ffmpeg.
- **Агент B (catalog/QA/docs):** T-1, T0.*, T2.*, T5.*, T6.2–T6.3.
- Один файл — один владелец-агент в рамках фазы.

## PR-шаблон (≤15 строк)

```
Задача: T<x.y>
Что сделано: <1-3 строки>
CI: <ссылка, статус>
Артефакты: <ссылки>
SHA-256 выходов: <...>
Следующий шаг: <T...>
Блокеры/вопросы владельцу: <или «нет»>
```

## Definition of Done (партия 1)

См. §3 в `docs/AGENT_PLAN.md`. Кратко: GLB в R2 → ретаргет male/female → QC → рендер (WebM alpha / WebP / poster / contact-sheet) → ревью владельца с телефона → PR в forma.
