# Архив

Архив провалившихся процедурных экспериментов.

**НЕ использовать как руководство.** См. `AGENTS.md` правило 2 и `docs/AGENT_PLAN.md`.

Содержимое `experiments/`:
- `grip_*.js` — попытки процедурного хвата / IK
- `bake*.mjs`, `build_*.mjs` — старые bake/build-скрипты
- `ANIMATION_CODE*.md` — описания процедурной анимации
- `back_squat.gd`, `bodyweight_squat.gd`, `animator_check*` — ранние GDScript-эксперименты приседа

Движения для продакшена берутся **только** из AnimStack пака / mocap (SportDemoAnimPack и далее). Процедурная генерация углов/ключевых кадров запрещена.
